# 匿名学生A｜数学个辅阶段方案

本方案依据某阶段的课堂反馈，结合沪教版教材及2024—2026年春考本地整理稿拟定。它是50个数学教学单元的建议，不是50天的固定课表；当前学校进度、近期试卷和实际可用时间需先核对。

## 先了解孩子：有思路，更需要把方法留住、用出来

孩子愿意提出具体疑问，也能如实说明哪些题是猜对的。课堂中，经过拆解和提示，她常能跟上思路、完成其中的计算。下一阶段的核心，不是把题讲得越多越好，而是让她在理解之后，能自己开始、写出关键步骤，过一段时间再做时仍能调用。

- **已经看到的进步**：前次课堂切线题中，前两步能自己完成，建立题设关系需要提示；后次课堂能写出切线方程，在关系建立后自己求解。这个进步发生在特定课堂题目和帮助条件下，还不能说明换题后已经稳定。
- **当前优先关注**：前次课堂多数基础求导公式回答正确；后次课堂又出现指数求导、商法则及化简错误。函数和导数综合题常需提示才能连起定义域、判号与结论，说明公式保持和方法调用需要复查。
- **可利用的优势**：此前课堂她主动追问单调性和图形建模中的疑惑，还独立找到过复数反例。教学中可以保留她提问、解释的空间，逐步减少提示。
- **已有基础但仍需辨析**：三角练习曾有整页核对正确；向量夹角方法有基础，但数量投影与向量投影需要区分。这些表现不能推断整个板块已经掌握。
- **作业与其他板块**：现有资料记录了作业布置，但缺少完整提交和验收记录，不能判断完成率。数列、空间几何、概率等板块先根据近期试卷和首课表现诊断，不预先判为薄弱。

## 为什么这样安排

| 已见情况 | 对应安排 | 教师怎样确认 |
| --- | --- | --- |
| 导数公式有时能答对，隔时又出现错误 | 前9课优先复习函数、求导、切线和单调性 | 课堂先独立尝试，之后选旧题隔时再做，记录需要的提示 |
| 知道某些步骤，但综合题不易确定入口 | 用代表题串联条件、方法和结论，再做少量变式 | 看能否解释第一步为什么这样选，而不是只核对答案 |
| 三角和向量有部分基础，也有公式与概念混淆 | 在教材核心板块复习中安排三角公式、解三角形和向量投影 | 先复查具体概念，再依据错因选题，不把整个章节都当薄弱 |
| 对其他板块及当前进度缺少近期证据 | 先诊断，再调整教材各板块的实际比重 | 结合学校卷、作业和首课独立表现，不凭旧记录猜测 |

## 50课整体路线

课次是可调整的教学单元编号，并非50天；课表顺序可根据诊断和考试结果调整。综合专题以代表性基础为先，不保证一课覆盖全部子点。

### 第1—9课｜诊断与重点修复

复查函数基础、导数公式、运算、切线、单调性及简单图像。**预期目标**：基础题能先独立确定定义域和方法，写出主要步骤；切线题能说明给定点是否为切点，并尝试建立条件。首课后根据实际结果决定比重。

### 第10—33课｜教材核心板块复习

覆盖集合与逻辑、不等式、指数对数、三角、向量、复数、立体与解析几何、数列、计数、概率和统计。**预期目标**：在每个板块能识别基本题型，复述核心条件，并完成代表性基础题；对没有近期证据的内容，先测后定。数学归纳法、随机变量分布和成对数据统计等内容，需核对实际教材及目标考试要求。

### 第34—38课｜阶段复测与分类汇编

第34课复测函数与导数，第35—38课计划把学校卷、练习、真题和模卷中实际出现的代表题按板块与错因整理。**预期目标**：区分公式遗忘、概念混淆、方法入口和运算问题；从汇编中选题隔时重做。汇编尚未制作，需先收集并核验材料；第35—38课也可按需要穿插在后续考试之间。

### 第39—50课｜真题、模卷与讲评

拟安排3套模卷和3套春考真题，各自独立作答后，安排对应讲评，共6次作答、6次讲评。**预期目标**：通过真实作答过程观察基础失分、步骤表达与时间分配，并在讲评后复做代表题。具体年份、卷源与答案尚待选择核验；单次成绩不作为趋势结论。

## 家长怎样看到变化

建议在第10、20、34、50课后沟通一次，可根据实际课表调整。每次用一页简要反馈说明：本阶段实际学过什么；哪些题能独立完成、哪些仍需提示；隔时重做的结果；下一阶段要保留或调整什么。以上是拟定的反馈机制，不表示已经实施。

如果同一类题仍反复卡住，先判断是公式、概念、审题还是运算问题，再换讲法或调整后续课次，不以赶完50课为目标。家长帮助保留近期试卷、作业和孩子自己的尝试，提供稳定的学习与休息时间即可，不必代讲或额外加卷。

## 模考与课时：有一项需要先约定

当前方案把每次完整作答和每次对应讲评分成不同的教学单元。整卷作答须按照所选试卷规定的时长留足连续时间，不能套用普通专题课60—90分钟；讲评另安排。

**整卷独立作答是否计入双方约定的个辅课时或收费课时，尚未确定，需师生及家长事先确认。**如果不计入，现有“34次专题＋4次汇编＋6次作答＋6次讲评”的50单元结构需要重新调整，不能直接理解为50次教师面对面授课。
