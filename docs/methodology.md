# 从课堂证据到50课个辅方案

## 使用目标

让教师与家长共同理解：学生已能做到什么、仍卡在哪里、为什么这样排课，以及怎样验证变化。此方法不是诊断量表，不通过一份反馈生成能力分数，也不承诺提分。

## 工作过程

1. **整理证据**：按知识板块提取真实课堂表现、学生尝试、提示条件和任务状态；保留教师内部来源。对外仅保留去标识的教学摘要。
2. **区分表现层级**：回答公式、提示后完成、无提示完成、隔时保持和变式迁移分别记录，不把“讲过”视为“掌握”。
3. **选定主线**：从反复出现、影响后续学习的卡点入手。这个匿名案例将函数、导数和独立建立关系前置，其他板块先诊断再调整。
4. **对照教材**：以册次与章节建立课程覆盖表。章节覆盖不等于每课讲完所有内容；统计分布等范围需核对实际教材和目标考试要求。
5. **定位真题考点**：按原题题号核对，而非只信解析标签；本地转录稿可能有错，教学前回可靠原卷和答案核验。真题不是预测依据。
6. **规划50单元**：34次诊断/专题、4次汇编、6次整卷作答、6次讲评。考试按卷面规定连续计时；计费口径须另行约定。汇编可穿插到考试之间。
7. **向家长呈现**：先学情、再选择理由、再四段路线及反馈节点，最后展开每课细目；不以50行课程表替代沟通。
8. **实施后调整**：建议在第10、20、34、50课后回看实际教学内容、独立表现、隔时保持和下一步调整，不能先填完成结果。

## 教师记录的最小字段

题目来源；独立完成到哪里；具体提示；错误类型；订正；隔时复查；下一步。仅在教师的私有系统内保留可识别学生资料，不上传到本仓库。

## 公开与不公开

公开：网页源代码、原创规划与方法、50课结构数据、匿名化后的教学证据摘要，以及发布者声明获准转载的第三方教材章节与真题材料。

不公开：学生姓名、精确课堂日期、录音、完整逐字稿、同学成绩、健康及接送信息、教师评价、个人本机路径、任何认证凭据。匿名案例仍是经过概括的真实教学摘要，不是虚构实测或可据以识别学生的完整档案。不能保证任何脱敏案例绝无重识别风险。

## 局限

本仓库没有实施效果数据；未独立全面审定数学答案；未核验第三方授权证明的真实性；课程先后、试卷版本和收费课时需要实际协商。教材章节和三年春考稿只是本次参考资料，不是完整考试大纲。
